## Git pull instructions:

### Prerequisites:
1. Check your terminal is in the project path (not parent folder of Varithon, but backend/frontend project directory)
2. Use repository of your name only `git checkout <your_name>`
3. Refer to other instructions in this directory

### Whenever you pull the latest changes from git, follow:

1. `git pull origin atharv`
2. `npm i` or `npm install`

### Whenever you push your new changes:

1. `git add -A` to track your new changes
2. `git commit -m "<commit_name>"` to create checkpoints (commits) of these new changes
3. `git push origin <yourname>` to push that to github
